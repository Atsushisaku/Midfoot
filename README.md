# Midfoot — スクワット姿勢可視化

スクワットのしゃがみ方を、インストラクターがクライアントに説明するときに使うツール。

伝えたい核心はひとつ：

> **上体の傾き量は体格（各セグメント長の比）と担ぎ位置の関数であり、技術の優劣ではない。**

「上体が起きたままできる人」と「傾けないとできない人」がいることを、その場で図で示せるようにする。

**→ https://atsushisaku.github.io/Midfoot/**

## 使う

タブレット横持ちを想定。キーボード入力は一切不要で、スライダーとボタンだけで操作する。

- **ハイバー／ローバー** — 押した瞬間に上体が傾く。最大の見せ場
- **靴（フラット／20mm／リフティングシューズ）** — 足首の可動域の天井が動く
- **体型プリセット** — 標準／大腿が長い／上体が長い／脛が長い
- **深さ** — 立位からボトムまで連続。バーが常に中足部の垂直線上を動くことが見える
- **足首の硬さ** — 上体角度に対する支配力が全入力中で最大
- **体格を固定** — 2体を並べて比較（「私はこう、あなたはこう」）

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm test         # ユニットテスト（幾何モデル）
npm run report   # 上体角度の一覧表を出力（数値調整用）
npm run build    # dist/index.html を単一ファイルで出力
```

成果物は **単一 HTML（約 20 KB）**。オフラインで動く（ジムの Wi-Fi 環境が悪い前提）。

唯一の外部参照はアクセス計測（GoatCounter）の `<script>` 1 行で、これは `async` なので
**取得に失敗してもアプリは通常どおり動く**。Cookie も IP も保存しない。計測が不要なら
`index.html` の該当行を消せば、外部参照ゼロの単一 HTML に戻る。

`main` に push すると GitHub Actions がテストを通してから Pages に公開する。
電波が不安な現場で使うなら、公開ページをブラウザで保存するか `dist/index.html` を
タブレットに置いておけば、ネットなしで同じものが動く。

## 構成

| ファイル | 役割 |
|---|---|
| `src/geometry.ts` | 幾何モデルと解法。純関数のみ、DOM 非依存 |
| `src/geometry.test.ts` | ユニットテスト |
| `src/presets.ts` | 体型プリセットとスライダー範囲 |
| `src/render.ts` | SVG 描画 |
| `src/app.ts` | 状態・UI・補間アニメーション・URL 共有 |

`geometry.ts` を純関数に切り出してあるのが要点。つま先浮き・θ_t の範囲外・深さ補間の反転は
境界条件が多く、目視では回帰を検出できない。

## モデル

矢状面の 2D スティックフィギュア。未知数は脛・大腿・上体の3角度、制約は
「股関節が目標深さにある」「バー＝システム重心が中足部の真上にある」の2つ。
**3未知数・2制約なので1自由度残る**ので、そこに「足首の可動域を何割使うか」を入力として与える。

詳細と、実装中に判明してモデルを変更した経緯は [`docs/squat-visualizer-spec.md`](docs/squat-visualizer-spec.md) に全部書いてある。

## やらないこと

3D 表示、関節トルクの絶対値計算、動画解析、実測値（cm）の入力、スタンス幅・股関節外旋
（矢状面 2D では表現不可。注記のみで対応）。

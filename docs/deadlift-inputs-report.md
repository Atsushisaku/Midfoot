# デッドリフト版の検討 — 入力は何にすべきか、何が重要な因子か

2026-07-30。デッドリフト版 Midfoot を作るかどうか・作るなら何を入力にするかを決めるための
事前検討。数値はすべて本文 §3 の簡易幾何モデル（スクワット版と同系の矢状面 2D）による。

---

## 0. 結論の要約

**入力の推奨**（詳細は §5）:

| 入力 | 判断 | スクワット版との対応 |
|---|---|---|
| 脛・大腿・体幹の長さ比 | 流用 | 同じ |
| **腕の長さ比** | **新規・必須** | （なし — DL 固有） |
| バーセッティング（標準プレート／ブロック／デフィシット） | 新規 | 「靴」トグルの枠 |
| 残り1自由度 =「股関節の高さ」（または脛の前傾） | 新規 | 「足首 ROM 使用率」の枠 |
| グリップ幅（通常／スナッチ） | 任意 | ハイバー／ローバーの枠に近い |
| 深さスライダー | **廃止**（開始姿勢が主題） | — |
| 足首 ROM | ほぼ不要（§5-6） | 最重要 → 重要度が激減する |
| スモウスタンス | 見送り（矢状面 2D で表現不可。スタンス幅見送りと同じ判断） | — |
| 身長の実測値 | 省略可（効果 ±1° 程度。§4-5） | — |

**最重要の発見**: 「腕の長さ依存度が高いから作っても…」という直感は**半分だけ正しい**。
腕長が効くのは①挙上距離（1cm 長いと引く距離が 1cm 減る、比例 100%）と②開始時の股関節の
高さ（+0.8cm/cm）であって、**開始姿勢の背角はほとんど変えない（+0.3°/cm）**。
背角を決めるのは大腿長・体幹長・膝の前後位置であり、これはスクワット版のテーゼ
「上体の傾きは体格の関数であって技術の優劣ではない」がそのまま成立する。
つまり腕長依存は「作る意味がない」理由ではなく、**世間の誤解（腕が長い＝背中が立つ）を
数字で正せる見せ場**になる。

---

## 1. スクワット版と何が構造的に違うか

### 1-1. 「深さ」が消え、「バーの高さ」が絶対値で固定される

スクワットは深さが自由変数だった。デッドリフトは**バーの初期高さが床からプレート半径
22.5cm（20kg/45lb 標準プレート）で万人共通に固定**される。主題は「しゃがみの連続変化」
ではなく**開始姿勢（セットアップ）そのもの**になる。

これは初めて**絶対スケール**がモデルに入ることを意味する（プレートは体格に比例して
くれない）。ただし感度は小さい（§4-5）ので、実測 cm 入力を排する方針は維持できる。

### 1-2. 腕が運動連鎖に加わり、「肩の位置が空間に固定される」

腕はほぼ張力部材（引っ張りしか伝えない）なので、一次近似で**鉛直**。すると:

> **肩の位置 = （中足部の真上, バー高さ 22.5cm + 腕長）で空間に釘付けになる。**

これが DL 幾何の核心。スクワットでは肩（担ぎ点）は体側の自由端だったが、DL では
バー側から拘束される。「腰を下げたい／上げたい」と思っても、肩は 1mm も動かせない。

### 1-3. 自由度の勘定はスクワットと同型（これは朗報）

未知数は脛・大腿・体幹の 3 角度。拘束は「肩が固定点にある」の 2 本（x, y）。
**3 未知数 − 2 拘束 = 残り 1 自由度** — スクワット版とまったく同じ構造なので、
ソルバの作りも UI の作り（残り自由度を 1 本のスライダーに割り当てる）も流用できる。

残り 1 自由度の正体は「**膝をどれだけ前に出すか**」＝ 実務では「**股関節を高くするか
低くするか**」。現実にはシャフトが脛に触れる位置でほぼ閉じる（既定値にする）が、
これをスライダーにすると「腰の高さは高めか低めか」という**コーチング上の定番論争を
そのまま操作できる**（§4-2）。

## 2. 検討に使ったモデル

スクワット版と同じ思想の矢状面 2D スティックフィギュア。

- セグメント長は身長比の標準値（Drillis & Contini 系）:
  足首高 0.039H、脛 0.246H、大腿 0.245H、体幹（大転子→肩峰）0.288H、
  腕（肩峰→グリップ中心）0.380H、足首→中足部の前方距離 0.040H
- 拘束: バー =（中足部真上, 床から 22.5cm）。腕は鉛直 → 肩 =（バー x, バー高 + 腕長）で固定
- 閉じ方（残り自由度の既定値）: 膝はバーの 0.020H（≒3.4cm）前 — シャフトが脛に触れる位置
- 股関節は「膝まわり半径・大腿」と「肩まわり半径・体幹」の円交点（後方解）で一意に決まる
- 基準体格: H=170cm、標準比率

読み方: **背角は水平から測る（0°=水平、90°=直立）。大きいほど「立っている」**。
基準の解は背角 40.2°・股関節高 55.5cm・脛の前傾 14.1° — 実際のコンベンショナル DL の
開始姿勢（背角 40〜50°）と整合する。

## 3. 感度分析の結果

各因子を単独で動かしたときの開始姿勢の変化（基準: 背角 40.2°、股関節高 55.5cm、
股関節→バー水平距離 37.4cm）。「股→バー水平」は股関節伸展モーメントアーム、
すなわち**腰・股関節への負荷のスケール**。

| 条件 | 背角 | Δ背角 | 股関節高 | 股→バー水平 |
|---|---|---|---|---|
| 基準 | 40.2° | — | 55.5 cm | 37.4 cm |
| 腕 +2cm | 40.8° | +0.6° | 57.1 cm | 37.1 cm |
| 腕 −2cm | 39.6° | −0.5° | 53.9 cm | 37.7 cm |
| 体幹 +2cm | 42.0° | +1.9° | 53.0 cm | 37.8 cm |
| 体幹 −2cm | 38.3° | −1.8° | 58.0 cm | 36.8 cm |
| 大腿 +2cm | 37.2° | **−3.0°** | 57.5 cm | **39.0 cm** |
| 大腿 −2cm | 43.1° | **+3.0°** | 53.6 cm | 35.7 cm |
| 脛 +2cm | 39.6° | −0.6° | 55.9 cm | 37.7 cm |
| ブロック +5cm | 41.9° | +1.8° | 59.4 cm | 36.4 cm |
| デフィシット −5cm | 39.0° | −1.2° | 51.3 cm | 38.0 cm |
| 小径プレート (r=15cm) | 38.7° | −1.5° | 49.0 cm | — |
| スナッチグリップ（実効腕長 −6cm） | 38.9° | −1.3° | 50.4 cm | 38.1 cm |
| 【自由度】脛ほぼ鉛直 | 36.3° | **−3.9°** | 58.1 cm | 39.5 cm |
| 【自由度】膝をより前へ (3.5%H) | 44.1° | **+3.9°** | 53.0 cm | 35.2 cm |

身長（比率同一・プレート絶対寸法）: 155→185cm で背角 40.9°→39.7°（**1.2° しか動かない**）。

挙上距離（別計算。ロックアウトのバー高 = 直立肩高 0.818H − 腕長）:
基準 52.0cm。**腕 ±2cm で ∓2cm（1:1 で比例）**。ブロック/デフィシット ±5cm も 1:1。

### 因子の重要度ランキング（背角に対して）

1. **残り自由度（膝の前後 ＝ 股関節の高さ）: ±4°** — スクワット版で足首 ROM が最大因子
   だったのと同じ構図。「選べる幅」は股関節高で ±2.5cm 程度あるが、**その帯の中心を
   体格が決める**。
2. **大腿長: ±3°/2cm** — 背角にもモーメントアーム（+1.6cm/2cm）にも最も効く体格因子。
   「大腿が長い人の DL がきつい」の正体はこの両方。
3. **体幹長: ±2°/2cm** — 長いほど腰が低く・上体が立つ（通説と一致）。
4. **バーセッティング: 1〜3° ＋ 挙上距離 ±5cm** — ブロック/デフィシットのトグルは
   スクワット版の「靴」に相当する良い見せ場。
5. **腕長: ±0.6°/2cm（背角には小）** — ただし股関節高 ±1.6cm、挙上距離 ∓2cm。
6. 脛長・身長: 小（±0.6°、±1°）。

### 腕長について（今回の主要な学び）

腕が 2cm 長いと、肩の固定点が 2cm 上がり、連鎖を通じて股関節も 1.6cm 上がる。
**上体ユニット全体が持ち上がるだけで、体幹の傾き自体はほぼ変わらない**（+0.6°）。
腕長の実利は「姿勢が楽になる」ことではなく、

- **仕事量**: 挙上距離が 1:1 で短くなる（±2cm は基準 52cm の ±4%）
- **相対バー高**: 手が低く届く ＝ 実質「ブロックから引いている」のと同じ

という形で現れる。世間の「腕が長い＝背中が立つ」は、正しくは「腕が長い＝**腰が高い**」。
背角を見て「腰が高すぎる」と直すのは、腕長差を無視した誤指導になり得る — これは
エラー解説アプリ（将来構想）のネタでもある。

## 4. モデル化上の論点（実装前に決めること）

1. **腕鉛直の近似**: 実際はラット（広背筋）がモーメントを伝えるので肩はバーの 2〜5cm 前に
   出る。v1 は鉛直で開始し注記で対応。肩前方オフセットを定数で持てばいつでも入れられる。
2. **バランス拘束の扱い**: 離地前はバーが床上にあるので「系重心が中足部上」の拘束は
   本来効いていない（効くのは離地の瞬間から）。スクワット版と同じ「バー＝系重心」近似で
   「バーは中足部の真上」を使う。高重量前提なら妥当、注記は必要。
3. **挙上アニメーション**: バー高さをパラメータにすれば同じソルバで各高さの姿勢が出るが、
   挙上中に膝がいつ後退するか（閉じ方の軌道）は一意に決まらず、個人差の実態も大きい。
   **v1 は開始姿勢に絞るのが安全**。動かすなら v2 で。
4. **背中の丸まり**: 実効体幹長の短縮としてモデル化できる（丸めると −2cm 相当 → 背角が
   立ち股関節モーメントアームが減る ＝「なぜ人は丸めたくなるのか」まで説明できる）。
   これも将来のエラー解説アプリの素材。
5. **絶対スケール**: プレート 22.5cm は絶対値なので厳密には身長入力が要るが、感度が
   1.2°/30cm しかないので **H=170cm 固定で十分**。「実測 cm を入力させない」方針を守れる。

## 5. 入力（UI)の提案まとめ

1. **体格スライダー 4 本**: 脛・大腿・体幹（流用）＋ **腕**（新設。範囲は同じ 0.8〜1.25 で可）
2. **体型プリセット**: DL 文脈で作り直す — 標準／腕が長い／大腿が長い／体幹が長い。
   「腕が長い」プリセットが股関節高だけ動かして背角を動かさないのが第一の見せ場
3. **バーセッティング トグル**: 標準（22.5cm）／ブロック +5cm／デフィシット −5cm／
   小径プレート（15cm）。「靴」トグルの後継。初心者に小径プレートで引かせることの
   意味（実質デフィシット）も見せられる
4. **残り自由度スライダー**: 「股関節の高さ」として見せる（範囲 ±2.5cm 程度、既定は
   シャフトが脛に触れる位置）。**「腰の高さは好みで選べるが、選べる幅は数 cm しかなく、
   帯の中心は体格が決める」**が第二の見せ場
5. **グリップ**（任意）: 通常／スナッチ（実効腕長 −6cm）。スナッチ DL が「腕を短くして
   わざとデフィシットを作る種目」であることが 1 タップで見える
6. **足首 ROM は原則出さない**: 基準の脛前傾は 14° で、スクワットと違い天井に当たらない。
   ただし「硬め 15°」の人はギリギリなので、残り自由度スライダーの上限を ROM でクリップ
   する形でだけ使う（新規入力にはしない）

## 6. 作る価値があるか（当初の疑問への回答)

「腕長依存だから作ったところで」への答え: **腕長は形（背角）をほぼ決めない**ので、
スクワット版の核心テーゼ「姿勢は体格の関数で、技術の優劣ではない」は DL でも成立し、
むしろ拘束が 1 本増える分（肩が空間に固定される）**「選べない」ことの説得力は
スクワットより強い**。見せ場の候補:

- 腰の高さ論争に「選べる幅は数 cm、帯の中心は体格」と数字で答える
- 「腕が長い＝背中が立つ」の誤解を正す（立つのではなく腰が上がる・引く距離が減る）
- 大腿長 → 背角とモーメントアームの両方に効く最大の体格因子
- ブロック／デフィシット／小径プレートの意味が 1 タップで見える

懸念はトグルの「派手さ」がスクワット版（ハイバー/ローバーの瞬間切り替え）より弱いこと。
最大の動きを作るのは残り自由度スライダーと大腿プリセットで、差は 3〜4° と控えめ。
「劇的に傾く」より「**どう動かしてもほぼ変わらない（＝選べない）ことを見せる**」アプリに
なる。そこを価値と割り切れるかが判断ポイント。

## 7. 将来構想（エラー選択アプリ）との接続

骨格入力 → 最適フォーム提示 → よくあるエラーを選択して悪影響を説明するアプリ構想
（2026-07-30）にとって、DL はエラーの幾何が明快で相性が良い:

| よくあるエラー | 幾何的な帰結（このソルバで計算可能） |
|---|---|
| バーが中足部より前（体から離れる） | 股関節・腰椎モーメントアームが cm 単位で直接増える |
| 腰が先に上がる（hips shoot up） | 背角が水平化 → 同じバー高でも股→バー水平距離が増える |
| 肩がバーの後ろに入る | 腕が斜め前方 → バーが前へ振られる（鉛直拘束の破れとして表現） |
| 背中の丸まり | 実効体幹長の短縮 → モーメントアーム減（「楽になる理由」まで示せる） |
| 開始時に膝が前すぎ | バーが膝を迂回する軌道になる（バー鉛直軌道の破れ） |

開始姿勢ソルバ（§2）はそのまま将来構想の土台になる。
